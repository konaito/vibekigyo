## 📌 プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | vibe起業.md |
| 概要 | AI×ビジネスフレームワーク融合型の企画書・技術仕様書生成プラットフォーム |
| 目的 | 新規事業開発における「壁打ち相手不在」問題を解決し、構造化された思考支援を提供 |

## 🎯 デュアルアプリケーション

### 💼 vibe起業.md （ルートパス: `/`）
**ビジネス企画書生成に特化したAIアシスタント**

- **ターゲット**: スタートアップ起業家、企業内新規事業担当者、学生・研究者
- **機能**: 事業アイデアから包括的なビジネス企画書を生成
- **セクション**: プロジェクト概要、ターゲットユーザー、価値提案、競合分析、収益モデル、マーケティング戦略、リスク分析、今後の戦略

### ⚡ vibeアプリ.md （パス: `/code`）
**技術仕様書生成に特化したAIアーキテクト**

- **ターゲット**: 技術アーキテクト、プロダクトエンジニア、開発チーム
- **機能**: ビジネスアイデアから詳細な技術実装仕様書を生成
- **セクション**: プロジェクト概要、技術仕様、UI/UX設計、機能仕様・API設計、画面・コンポーネント設計、開発スケジュール、開発・運用戦略、技術的リスク・課題

### 🔄 seamless連携機能
- **データハンドオフ**: vibe起業.mdで作成した企画書をvibeアプリ.mdに自動受け渡し
- **技術的実現**: localStorage + URLパラメータによる安全なデータ転送
- **ワークフロー統合**: 事業企画 → 技術仕様の一貫した開発フロー

## ✨ 革新的な機能

### 🚀 コア機能
- **AIチャット**: OpenRouter API (GPT-4o) による自然言語対話
- **リアルタイム文書生成**: 会話内容に基づくMarkdown自動更新
- **3つのAI応答タイプ**: chat（会話のみ）/ update（更新のみ）/ chat+update（両方）
- **構造化テンプレート**: 用途別の最適化されたセクション構成

### ✏️ インライン編集システム（v1.0新機能）
- **セクションタイトル編集**: タイトルをクリックして直接編集
- **コンテンツ編集**: 本文をクリックしてMarkdown形式で直接編集
- **キーボードショートカット**: Cmd+S（保存）, Esc（キャンセル）, Enter（タイトル保存）
- **視覚的フィードバック**: ホバー時の青枠表示・スケールアニメーション

### 🤖 AIコンテキスト連携
- **編集通知システム**: 手動編集内容をチャットに自動送信
- **AI理解促進**: 編集された内容をAIが把握し、文書の雰囲気・方向性を理解
- **seamlessコラボレーション**: 人間の編集とAI生成のハイブリッド執筆

### 📤 エクスポート・共有機能  
- **クリップボードコピー**: ワンクリックでMarkdown全文コピー
- **ファイルダウンロード**: 日付付き.mdファイルとして保存
- **アプリ間連携**: vibe起業 → vibeアプリへのワンクリック転送

### 🎨 モダンUX
- **2パネルレイアウト**: チャット画面とMarkdownプレビューの同時表示
- **共通コンポーネント設計**: 800行以上のコード重複削減
- **レスポンシブデザイン**: Tailwind CSSによるモダンで美しいUI
- **独立スクロール**: 左右パネルが独立してスクロール

## 🚀 セットアップ・使用方法

### 前提条件
- **Node.js 18+** または **Bun 1.0+**
- **OpenRouter API キー** ([openrouter.ai](https://openrouter.ai)で取得)

### 環境構築
```bash
# リポジトリクローン
git clone https://github.com/konaito/vibekigyo.git
cd vibekigyo/frontend

# 依存関係インストール
bun install

# 環境変数設定
cp .env.local.example .env.local
# .env.localにOPENROUTER_API_KEYを設定

# 開発サーバー起動
bun run dev
```

### 使用方法

#### vibe起業.md（事業企画書）
1. **ルートアクセス**: `http://localhost:3000/`
2. **デモ確認**: 右側にvibe起業.mdの企画書が表示
3. **新プロジェクト開始**: 最初のメッセージでテンプレートにリセット
4. **対話**: ビジネスアイデアを自然言語で入力
5. **編集**: セクションをクリックして直接編集
6. **転送**: 「エクスポート(vibeアプリ)」で技術仕様書作成に移行

#### vibeアプリ.md（技術仕様書）
1. **直接アクセス**: `http://localhost:3000/code`
2. **企画書からの転送**: 自動で事業内容を受け取り
3. **技術対話**: 技術要件・アーキテクチャを詳細化
4. **仕様書生成**: 開発着手可能な技術仕様書を作成
