# 📘 vibe起業.md - AI駆動企画書生成アプリ

> 起業家がAIとの対話を通じて構造化された企画書を効率的に作成できるツール

---

## 📌 プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | vibe起業.md |
| 概要 | AI駆動の企画書生成チャットアプリケーション |
| 目的 | 起業家がAIとの対話を通じて構造化された企画書を効率的に作成できるツールを提供 |
| MVP版リリース | v0.1 完成済み ✅ |
| 開発期間 | 2025年1月 |

## 🎯 ターゲットユーザー

- **スタートアップ起業家**: アイデア段階から事業計画を体系化したい人
- **個人事業主**: 新規事業の企画書作成が必要な人  
- **企業内新規事業担当者**: 社内提案用の企画書を効率的に作成したい人
- **学生・研究者**: ビジネスプランコンテスト等で企画書が必要な人

---

## 💡 主な機能

### ✨ コア機能
- **AIチャット**: OpenRouter API (GPT-4o) による自然言語対話
- **リアルタイム企画書生成**: 会話内容に基づくMarkdown自動更新
- **3つのAI応答タイプ**: chat（会話のみ）/ update（更新のみ）/ chat+update（両方）
- **構造化テンプレート**: プロジェクト概要、ターゲット、機能、技術、スケジュール

### 📤 エクスポート機能  
- **クリップボードコピー**: ワンクリックでMarkdown全文コピー
- **ファイルダウンロード**: .mdファイルとして保存可能

### 🎨 UX機能
- **2パネルレイアウト**: チャット画面とMarkdownプレビューの同時表示
- **レスポンシブデザイン**: Tailwind CSSによる美しいUI
- **リアルタイム更新**: タイピング中のローディング表示
- **独立スクロール**: 左右パネルが独立してスクロール
- **キーボードショートカット**: `⌘+Enter`で送信（Enterで改行可能）
- **デモ→実用切替**: 初回メッセージでテンプレートに自動リセット

## 🌐 API仕様

### `/api/apply-instruction` (POST)

#### リクエスト
```json
{
  "instruction": "カメラアプリを作りたい",
  "sections": {
    "📌 プロジェクト概要": "| 項目 | 内容 |\n|------|------|\n| プロジェクト名 | 未定 |"
  },
  "messages": [
    { "role": "user", "content": "カメラアプリを作りたい" }
  ]
}
```

#### レスポンス（3タイプ対応）
```json
{
  "type": "chat+update",
  "message": "カメラアプリのプロジェクトですね！プロジェクト概要を更新しました。",
  "markdown": "{\"📌 プロジェクト概要\": \"| 項目 | 内容 |\\n|------|------|\\n| プロジェクト名 | カメラアプリ |\"}"
}
```

#### JSON Schema検証
- **厳密な型チェック**: OpenRouter API でレスポンス形式を強制
- **3つのタイプ**: `chat` / `update` / `chat+update`
- **エラーハンドリング**: 400/500エラーの適切な処理

## 🎨 アーキテクチャ

### システム構成
```
[ユーザー] ↔ [Next.js Frontend] ↔ [API Routes] ↔ [OpenRouter] ↔ [GPT-4o]
                     ↓
              [Markdown Engine] 
                     ↓
              [File Export System]
```

### データフロー
1. **ユーザー入力**: 自然言語でアイデア・要望を入力
2. **API処理**: OpenRouter経由でGPT-4oに送信
3. **AI応答**: JSON Schema準拠のレスポンス（type/message/markdown）
4. **状態更新**: React stateでチャット履歴とMarkdownセクション更新
5. **UI表示**: リアルタイムでチャット・企画書画面を更新

## 🚀 セットアップ・使用方法

### 環境構築
```bash
# 依存関係インストール
bun install

# 環境変数設定
cp .env.local.example .env.local
# .env.localにOPENROUTER_API_KEYを設定

# 開発サーバー起動
bun run dev
```

### 使用方法
1. **デモ確認**: 右側にvibe起業.mdの企画書が表示される
2. **新プロジェクト開始**: 最初のメッセージでテンプレートにリセット
3. **自然な対話**: アイデアや要望を⌘+Enterで送信
4. **リアルタイム更新**: 企画書が会話に応じて自動更新
5. **エクスポート**: コピーまたはダウンロードで保存
