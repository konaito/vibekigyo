Vibe Codingとは？ そして、vibe起業.mdの役割
“Vibe Coding（ヴァイブ・コーディング）”とは、自然言語で「やりたいこと」をざっくり伝え、LLM（大規模言語モデル）がソースコードを生成し、人間はテストと微修正だけで開発を進めるスタイルを指します。この概念は2025年2月にAndrej Karpathy氏によって提唱され、急速に注目を集めています。

従来の開発プロセスでは数週間～数ヶ月かかっていたMVP（Minimum Viable Product）開発が数日で可能になるなど、開発の「速度」がビジネスにおける重要な指標となりつつあります。

vibe起業.md と vibeアプリ.md は、このVibe Codingの思想をビジネス企画と技術仕様策定の領域に応用したツールです。AIとの対話を通じて、高品質な企画書や仕様書を迅速に作成することで、アイデアの具現化を加速します。

「英語（または日本語）＋レビュー」で動くこの新しいアプローチは、プロトタイピングとUI開発のスピードを飛躍的に向上させますが、品質と責任の担保が課題です。vibe起業.md は、構造化されたテンプレートとAI支援により、この課題に取り組み、"Good Vibes"な開発体験を提供します。

💼 vibe起業.md
ビジネス企画書生成に特化したAIアシスタント

ターゲット: スタートアップ起業家、企業内新規事業担当者、学生・研究者

事業アイデアから包括的なビジネス企画書を生成。プロジェクト概要、ターゲットユーザー、価値提案、競合分析、収益モデル、マーケティング戦略、リスク分析、今後の戦略などを網羅。

⚡ vibeアプリ.md
技術仕様書生成に特化したAIアーキテクト

ターゲット: 技術アーキテクト、プロダクトエンジニア、開発チーム

ビジネスアイデアから詳細な技術実装仕様書を生成。技術仕様、UI/UX設計、機能仕様・API設計、画面・コンポーネント設計、開発スケジュール、開発・運用戦略、技術的リスク・課題をカバー。

🔄 seamless連携機能
vibe起業.mdで作成した企画書をvibeアプリ.mdに自動受け渡し。localStorage と URLパラメータによる安全なデータ転送で、事業企画から技術仕様まで一貫した開発フローを実現します。

革新的な機能
AIとのシームレスな連携と直感的な操作性で、あなたのアイデアを加速します。

AIチャット (OpenRouter API - GPT-4o)
自然言語での対話を通じて、ビジネスアイデアや技術要件を具体化します。

リアルタイム文書生成
AIとの会話内容に基づいて、Markdown形式の企画書・仕様書をリアルタイムで自動更新します。

インライン編集システム
セクションタイトルや本文を直接クリックして編集可能。キーボードショートカットにも対応。

AIコンテキスト連携
手動編集内容をAIが把握し、文書の雰囲気や方向性を理解。人間とAIのハイブリッド執筆を実現。

エクスポート・共有機能

ユーザージャーニー
アイデアから開発着手まで、一貫したフローでプロジェクトを推進します。

1. 事業企画フェーズ
vibe起業.md
アイデア入力 → AI対話 → 企画書生成 → 手動編集 → 完成。ビジネスの骨子を固めます。

2. vibeアプリへ転送
連携
完成した企画書をワンクリックで vibeアプリ.md に転送。シームレスな連携を実現します。

3. 技術仕様フェーズ
vibeアプリ.md
企画書を受け取り → 技術要件対話 → 仕様書生成 → インライン編集 → 開発着手。技術的な詳細を詰めます。

4. シームレスな開発フロー
連携
企画から開発の断絶を解消し、ビジネス要件と技術要件の一貫性を確保。開発チームへの確実な要件伝達をサポートします。
